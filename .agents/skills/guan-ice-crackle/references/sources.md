# 官窑冰裂：来源与边界

## 已核实的馆藏资料

- 故宫博物院藏宋代官窑青釉圆洗：粉青釉纯净莹澈；釉层普遍较厚并多有开片，厚釉者常见大块冰裂纹。馆藏页亦提示官窑与哥窑片纹有所不同。
- 故宫博物院藏官窑粉青釉弦纹瓶：官窑釉色以粉青为主，器物多素面，装饰通常克制。
- 宋代官窑涉及北宋汴京及南宋杭州附近多个窑场，具体窑址与制度史存在研究讨论。此 Skill 不把一处窑场或单一年代概括为全部官窑。

## 设计转译

粉青、厚釉深度、大块不规则冰裂与素面审美用于建立视觉语言；屏幕渐变、图表纹理和文字配色属于现代设计转译，不应标作宋代原貌。
