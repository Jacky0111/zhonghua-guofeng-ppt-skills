# 官窑冰裂

按内容需要设计页面结构，使用官窑冰裂的设计语言建立视觉一致性。先阅读 `assets/README.md`，再按任务查看相关示例；历史主张以 `references/sources.md` 为准，并区分馆藏事实与现代转译。

## 视觉语言

- **色彩：** 粉青、灰青、月白及暖灰白为主；使用少量铁灰或含蓄的赭灰表现胎釉边缘和层次。粉青不是固定色值，按背景、显示条件及对比需求微调。
- **材质：** 表现厚釉的柔润、莹澈与有分量的深度。以较大的不规则冰裂片纹为主，可叠加较细裂纹；不套用定窑泪痕、汝窑细密蟹爪纹或哥窑金丝铁线。
- **版式与层级：** 根据内容密度、逻辑关系和展示重点选择构图。可将片纹放入背景、信息卡、图表或分隔区，并在正文密集处降低纹理对比度。示例是风格证据，不是页面模板。
- **字体与组件：** 标题可用端正的宋体风格，正文以清晰的现代黑体或易读宋体呈现。图表、表格和时间轴按信息关系设计，以粉青、灰青、铁灰建立层级，不强行套固定组件。
- **器物呈现：** 默认以抽象釉色和片纹表达风格，不要求生成瓷器。仅当内容明确需要器物时才加入器物图。
