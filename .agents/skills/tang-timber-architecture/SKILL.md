# 唐代木构

当用户希望以唐代木构建筑美学设计或改进幻灯片时使用。让页面结构响应内容长度、信息密度、逻辑关系和叙事用途。设计前先读 [`assets/README.md`](assets/README.md)；涉及历史背景或建筑事实时，按需查阅 [`references/sources.md`](references/sources.md)。

## 设计语言

- **色彩关系：** 以深木色建立沉稳骨架，朱红作为少量强调与节奏，土黄和暖白提供温润光感及可读空间。三者比例随内容调整；避免全页棕黄滤镜、红色边框化或只有纯色背景。
- **材质：** 以细腻且自然变化的木纹、木材明暗与斜向暖光表达材质深度。纹理应进入页面信息区、背景和局部组件，并随信息密度控制强度；不能只做孤立背景，也不能压过文字。
- **结构转译：** 将梁柱的横纵秩序转为信息层级和对齐节奏，将斗拱、榫卯的穿插承托转为组件之间的连接、叠层和视觉重心，将出檐的舒展感转为横向延伸与留白张力。它们是组织页面的设计原则，不是每页都要绘制的结构图。
- **气韵：** 追求雄浑、开阔、质朴、稳定而有空间感的当代表达。避免陈旧仿古页面、仿旧纸张堆叠、过度几何化、刻意展示榫卯，以及只有一块木纹或纯色的空洞背景。
- **内容自适应：** 年代关系可用时间叙事或对照；结构关系可用层级、路径或简洁图解；多类遗存可用错位编辑式分组；高密度内容可使用清楚的分区和短说明。根据真实内容决定组件，不把这些建议固化为模板。
- **灵活构图：** 改变页面重心、横纵方向、纹理流向、信息分组和留白。五张示例只提供视觉证据，不得照搬其整页布局、背景位置、文案或标注。
- **可读性：** 正文、小字和图表标注置于对比稳定、纹理较弱的区域。避开木纹高反差、强光和颜色交界；必要时使用稳定的阅读底色、局部降纹理或增强明暗对比。
- **史实边界：** 唐代木构横跨不同地域、类型和营造传统。南禅寺大殿、佛光寺东大殿是具体案例，不代表全部唐代建筑；不得将现代设计转译说成历史测色、建筑复原或通用形制结论。事实边界及资源中的图文局限见 `references/sources.md` 与 `assets/README.md`。

## 资源调用

开始设计前阅读 [`assets/README.md`](assets/README.md)。只有在需要校准风格时，才查看 `assets/examples/` 中相关页面角色的示例；从中提取木色层次、纹理密度、横向走势、朱红节奏、暖光与信息层级。不要复制页面文字、历史标注或完整构图；实际页面始终由输入内容驱动。
