# 唐代木构：史实来源与设计转译

## 可追溯来源

- [联合国教科文组织：Mount Wutai 提名文件](https://whc.unesco.org/document/152245) — 记录南禅寺大殿（782 年）和佛光寺东大殿（857 年）等具体建筑年代。
- [北京日报：佛光寺东大殿建筑信息与调查史](https://xinwen.bjd.com.cn/content/s68c56460e4b0221b9becd3e0.html) — 概述佛光寺东大殿题记、经幢、1937 年调查史及艺术遗存。相关主张应限定在该建筑个案。
- [殿堂型木构架柱架摇摆抗侧机理研究](https://pubs.cstam.org.cn/article/doi/10.6052/j.issn.1000-4750.2018.09.0494) — 研究特定殿堂型木构架及结构连接。不能将个案分析直接推广为所有唐代木构的统一模型。

## 事实与边界

- **已核实事实：** 上述资料将南禅寺大殿记为 782 年、佛光寺东大殿记为 857 年；佛光寺东大殿的题记、经幢与近代调查史属于该建筑的具体研究材料。
- **现代设计转译：** 深木色、朱红、土黄/暖白的色彩比例，以及木纹流向、横向延伸、承托叠层和斜向光影，均为现代演示设计语言，不是对唐代木料、颜料或建筑原貌的测色与复原。
- **适用范围：** “唐代木构”涵盖多个地域、类型、营造传统及后世修缮层次。使用具体史实、构造或遗存时，应标明建筑对象和来源，不把佛光寺、南禅寺的特点当作整个唐代的通则。
- **图像文字修订（2026-11-26）：** 原示例图中无法核实的来源脚注与书目题名已删除，超出来源的建造年代、壁画与题记表述已改写。梁思成关于佛光寺的论著见《中国营造学社汇刊》第七卷，引用时请核对原刊。

## 设计使用原则

以材料层次、空间秩序、横纵节奏和承托关系组织页面；除非输入内容需要讨论某座建筑或构件，不直接把殿堂、屋顶、斗拱或榫卯特写作为装饰。结构意象应进入信息层级和组件关系，而不是变成反复出现的建筑示意图。
