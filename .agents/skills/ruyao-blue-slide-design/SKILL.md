# 汝窑天青幻灯片设计

## 调用与资源读取

此 Skill 的资源路径均相对于本 `SKILL.md` 所在目录。调用时先阅读 `assets/README.md` 和 `references/sources.md`；至少查看主参考图 `assets/ruyao-blue-reference.png`。若任务涉及釉色层次、开片细节、信息页或组件转译，再按需查看对应的 `assets/examples/` 示例图。

这些图片用于提取汝窑天青的色彩、光泽、通透感、细开片、流动釉色及深蓝点缀等视觉特征，不是固定页面模板。不得复制示例的完整构图、元素位置或文案；应根据输入内容的类型、长度、信息密度和逻辑关系重新设计每页结构。

## 设计规则

- **内容驱动构图：** 根据内容选择页面比例、布局、视觉重点和信息组件；仅在用户或演示环境有要求时使用指定比例。不要把安静浅色背景、居中标题或任何示例布局固定为默认版式。
- **配色：** 以乳白、浅汝青、雾蓝、深墨蓝/钴蓝为基础。标题或标签、分隔线、图标、插图和装饰点缀等主要元素都应能看到蓝色。需要较强对比度的文字使用墨蓝。避免无关的鲜艳颜色；必要时可使用自然肤色和少量与内容相关的中性色。
- **参考色提示：** 瓷白 `#DBE0DD`、汝青 `#A4BFBB`、釉影 `#739392`、墨蓝 `#244150`、深蓝 `#245071`。这些颜色是取样参考，不是必须照搬的纯色填充；应保留柔和的色调变化。
- **材质与纹理：** 通过适度的釉色渐变、通透层次、柔和光泽、低对比度细开片和流动色层传达质感。纹理可按内容需要进入背景、信息卡片、图表或分隔区域；细节丰富处避开小字号正文，确保信息可读。陶瓷风格表达视觉感受，不要求生成或展示陶瓷器物。
- **组件：** 按数据与内容关系设计图表、时间轴、信息卡片和插图。将深蓝用作醒目但克制的强调色，避免厚重装饰边框。
- **插图：** 每张内容插图应与瓷器模板背景清楚区分。优先采用简洁、现代的编辑插画或扁平矢量风格，线条清晰、几何形状简单、明暗层次有限。插图沿用青瓷与蓝色系。
- **字体：** 中文正文使用黑色或深墨蓝色的宋体风格字体，并建立清晰的标题/正文层级。只有用户要求题字等书法元素时才使用表现性书法；其他幻灯片文字应清晰易读、风格克制。
- **信息层级：** 每页根据内容密度安排标题、正文和重点信息，不强制每页只有一个信息点。保留清晰易读的层级，避免文字溢出、页面过空或装饰过满。

## 避免事项

- 除非用户要求，否则不要用水彩或水墨画风格绘制内容插图。
- 不要把照片写实或绘画风格的场景混入瓷器背景；模板背景和内容插图应保持视觉分离。
- 不要加入与内容或青瓷蓝色系无关的装饰纹样、图标、渐变或强调色。
- 不要擅自编写幻灯片文案。保留用户提供的措辞；若缺少某个标签或主张会改变含义，应先询问。
- 不要依赖个人电脑上的绝对路径读取资源。所有图片引用必须使用相对于 Skill 目录的路径，并通过资源索引按需选择。
