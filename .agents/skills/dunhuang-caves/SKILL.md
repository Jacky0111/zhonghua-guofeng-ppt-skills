# 敦煌石窟

当用户希望以敦煌石窟艺术美学设计或改进演示文稿时使用。根据内容长度、信息密度、逻辑关系和叙事用途决定页面构图，以矿物色层、材料肌理、空间纵深与流动韵律建立风格一致性。开始设计前阅读 [`assets/README.md`](assets/README.md)；涉及年代、颜料、洞窟结构或丝路交流的事实时，按需查阅 [`references/sources.md`](references/sources.md)。

## 设计语言

- **色彩：** 以沙黄、赭红、石绿为核心，通过低饱和明暗、邻近色过渡与局部沉积感形成层次。色谱比例随内容变化；不得把某一洞窟或时代的历史颜料色彩概括为整套固定配色。指定色谱是现代设计转译，不是历史测色复原。
- **壁画与岩层质感：** 以细微矿物颗粒、哑光颜料层、自然色差、轻微剥蚀和岩壁肌理表达时间感。质感须细腻、真实、克制，避免做旧滤镜、脏污噪点、撕纸效果或廉价裂纹；不能只铺一张沙黄色背景。
- **空间与光影：** 通过前后层叠、局部遮挡、深浅递进、柔和侧光和留白营造洞窟般的幽深感。只表达空间气息，不画洞窟入口、崖壁窟口、连续门洞、土堡、城墙、瞭望塔或容易被识别为堡垒的建筑轮廓，也不展示完整石窟建筑。
- **构图韵律：** 将藻井的向心秩序、层级递进和几何节奏抽象为信息聚合、层级分组或局部构图重心；不照搬具体藻井图案，不要求每页使用圆形或中心对称。将飞天艺术的舒展、飘逸转为轻柔的线势、色带流向或页面节奏，不出现飞天人物或具象飘带。
- **内容自适应：** 年代与沿革可用时间线、阶段叙事或对照；颜料与保护内容可用材料层析、流程或比较；丝路交流可用关系路径、网络或空间叙事。以上只是可选表达，依据内容选择图表、表格、卡片和信息组件，不套用固定版式。
- **意象边界：** 不将佛像、飞天、莲花、佛教符号、完整壁画、洞窟外观或土堡式结构作为装饰。若输入内容必须讨论相关对象，优先用文字说明或抽象结构表达；只有用户另行明确要求具象呈现时才考虑使用，并核对来源与使用范围。
- **排版与可读性：** 标题可用有文化气质的宋体类字形，正文与标注优先使用清晰的现代字体；按环境可用字体选择，不依赖个人字体安装。正文、脚注、图表标注放在明暗稳定、低纹理区域，避开颗粒密集、高光和色层交界。必要时加阅读底色、降低局部纹理或增加留白。
- **史实边界：** 莫高窟的具体洞窟、年代、颜料和保存状态各有差异。来源资料中的单窟特征不可泛化；图像中呈现的颜色、纹理与空间均属现代设计转译，不是文物图像、壁画复原或历史原貌复原。详见 [`references/sources.md`](references/sources.md)。

## 多语言生成

本节优先于本 Skill 中任何与语言、字体或阅读方向有关的表述。

- **指令语言不等于输出语言：** 本文件用中文撰写，不限定演示文稿的语言。
- **自动决定输出语言：** 用户指定时按指定执行；否则依据用户本次输入的语言与意图自动判断（页面内容、请求措辞、上下文），不固定为任何语言，也不以仓库或指令语言为默认。支持任意语言及多语言混合。
- **原文不可擅改：** 不得擅自翻译、改写、简繁转换或转写用户提供的内容（含专名、引文、代码、数字与单位）。仅在用户明确要求时翻译。页面上的原文须逐字符一致（含标点、大小写、数字与单位）：不补句末标点，不替换全角、半角或其他标点；换行只改位置，不增删字符。指定的输出语言与原文不同且未说明是否翻译时，无须固定追问：依据用户输入自动决定新增文字的语言，所给原文保持原样。
- **按文字调整版面：** 依实际文字长度调整字号层级、换行、分栏与页数，不靠缩到难以阅读或裁切来塞入内容。
- **字体兼容：** 选用当前环境可用且覆盖目标文字的字体，避免缺字与伪造字形。本 Skill 提到的宋体、黑体等气质，在其他文字中换用相近的衬线或无衬线字体。
- **阅读方向：** 阿拉伯文、希伯来文等从右到左文字须调整对齐、阅读顺序与时间轴、流程方向；混排时数字、拉丁词与标点保持正确。仅在文字适用且内容需要时使用竖排。
- **适用范围：** 本节约束演示内容与版面。版式或“简短说明”类建议不授权删减、压缩用户原文；原文与可核查史实或本 Skill 的史实边界冲突时，指出问题，经用户确认后才修改。
- **换语言不换风格：** 色彩、材质、纹理、光泽、层次、格调与意境保持本 Skill 的设计语言。示例图中的中文只是示例，不得照抄，也不代表默认语言。
- **交付检查：** 调用图像生成时在提示词中逐字给出页面文字，并写明不得增删或替换标点。交付前对照画面实际文字与用户原文逐字核对（含每行行末）；不一致则修正或如实告知，报告以画面实际内容为准。同时检查缺字、错字、断行与方向。图像生成对该文字渲染不可靠时，改用可编辑文本层；做不到时如实告知用户。
