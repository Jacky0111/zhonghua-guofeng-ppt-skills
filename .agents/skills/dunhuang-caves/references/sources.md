# 敦煌石窟：历史资料与设计转译边界

## 可追溯来源

- [联合国教科文组织：莫高窟](https://whc.unesco.org/en/list/440/) — 记载莫高窟始建于公元 366 年，代表 4—14 世纪佛教艺术；现存 492 座洞窟、约 45,000 平方米壁画，并说明其位于丝绸之路贸易、宗教与文化交流的交汇地带。
- [敦煌研究院：《敦煌莫高窟壁画颜料及检测技术研究进展》](https://skytyz.dha.ac.cn/CN/Y2022/V1/I1/47) — 综述莫高窟壁画颜料与检测技术。具体颜料、绘制技法及其变化须结合洞窟、年代与检测证据判断。
- [敦煌研究院：莫高窟第 407 窟](https://www.dha.ac.cn/info/1425/3569.htm) — 记录隋代洞窟形制及窟顶藻井等具体信息。此单窟资料仅用于理解层级、向心秩序和装饰韵律，不可泛化为所有敦煌石窟的共同形制。

## 事实、转译与未知

- **已核实事实：** UNESCO 所述营建年代、艺术年代、现存洞窟和壁画面积均指莫高窟；敦煌研究院颜料研究关注颜料种类、分析检测和保护；第 407 窟的结构与图案是具体洞窟个案。
- **现代设计转译：** 沙黄、赭红、石绿的组合与比例，矿物颗粒的视觉强化、色层渐变、轻微剥蚀、空间光影、藻井向心层级和飞天流动线势，均为本 Skill 的现代设计语言，不是历史颜料配方、色彩测定或文物复原。
- **未知与边界：** 预览没有对某一洞窟进行颜料取样、色彩测量或建筑测绘，无法据此判定某色对应何种矿物、某一画面原始色相或洞窟的精确形制。涉及具体颜料、年代与图像内容时，需补充对应洞窟及可核查研究资料。

## 使用原则

让材料、空间和韵律服务信息表达，而非将宗教图像或完整壁画当作装饰。单窟的图案、颜料或形制只有在内容确需讨论时才作为事实材料，并注明对象范围与来源；风格调用本身不授权复制文物图像或参考图。
