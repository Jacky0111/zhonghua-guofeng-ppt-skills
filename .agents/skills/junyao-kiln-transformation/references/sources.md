# 钧窑窑变：来源与边界

## 已核实的馆藏资料

- 故宫资料记载钧窑以铁、铜呈色特点形成蓝中带红、紫斑、天青、月白等色；釉色以蛋白石光泽的青色为基调，呈乳浊、不透明效果。
- 故宫藏钧窑器物可见天蓝釉与紫红斑组合；部分器物还有不规则流动状细线，称“蚯蚓走泥纹”。
- “钧窑”涵盖不同时期和不同窑场，不能把某一件器物的颜色、形态或工艺归纳为所有钧窑产品的固定属性。

## 设计转译

蓝、紫红与深紫的流动渐变、屏幕光效、排版路径和组件色彩是现代视觉设计，不是古代釉色的精确复原。避免把窑变描绘成单一固定配方或火焰图案。
