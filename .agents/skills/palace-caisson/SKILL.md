# 宫廷藻井

让内容决定页面结构与信息密度。以层叠空间、石青与石绿的矿物色感、克制金色以及彩绘表面的时间肌理建立风格辨识度。开始设计前阅读 [`assets/README.md`](assets/README.md)；史实依据和诠释边界见 [`references/sources.md`](references/sources.md)。

## 设计语言

- **色彩：** 石青与石绿构成主要色层，金色用于少量焦点、细线或局部高光。按内容调整比例；不将本方案色彩比例说成所有宫廷藻井的历史定色。暖灰、纸色或深墨色可按页面可读性用作辅助底色。
- **材质：** 以矿物颜料颗粒、叠色边界、微弱磨损和沉积感转译彩绘历史。壁画式肌理是现代视觉表达，不表示藻井均为壁画材质；肌理应融入页面系统，不局限于孤立装饰图。
- **空间层次：** 从藻井的层叠与向上收束提炼纵深、聚焦和信息层级。方、八角、圆形关系只在内容适合时抽象引用，不必每页出现，也不作为固定边框或重复徽章。
- **具象边界：** 预览图中未复刻太和殿藻井的蟠龙衔珠。除非页面内容明确讨论某一历史纹样且具象呈现有助于理解，不直接使用龙、花卉、瑞兽或完整藻井图样；优先转译其色彩、疏密、结构节奏和空间意境。
- **内容自适应：** 结构解释可用剖解、层级标注或比较；历史与修缮内容可用时间线、材料层析或证据卡片；论述性内容可用大标题、短注与大面积留白。布局、组件和信息密度随输入变化，不套用示例图。
- **专业排版：** 标题、正文、注释与图表应在纹理上保持清楚的明暗对比。小字避开金色高光、复杂颜料颗粒和深浅交界，必要时为信息增加稳定的阅读底色或降低局部纹理强度。
- **史实边界：** 藻井跨越不同历史时期、建筑与工艺，不能将单一案例推广为普遍规则。石青、石绿等颜料信息来自特定建筑彩画样本，不自动等同于太和殿藻井的颜料检测结论。具体事实以 [`references/sources.md`](references/sources.md) 为准。
