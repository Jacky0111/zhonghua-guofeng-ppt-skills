# 宫廷藻井：史实来源与设计转译

## 已核实事实

- 故宫博物院将藻井说明为室内天花中央向上隆起的装饰，重要殿宇常见；其词条描述其由方井、八方井、圆井层叠构成。
- 太和殿宝座上方天花正中安置藻井，中心雕有蟠龙衔珠。故宫青少版资料称太和殿三层藻井为等级最高的宫殿藻井。
- 故宫东华门内檐彩画保护研究对具体彩画样本进行材料检测，记录石青、石绿、朱砂等颜料，并分析了颜料层、基层材料与不同阶段修缮痕迹。研究指出部分层位的具体解释仍待更多案例验证。
- 东华门案例属于特定建筑彩画与天花样本，不能直接当作太和殿藻井或所有宫廷藻井的材料检测结论。

## 现代设计转译

本 Skill 采用金色、石青、石绿为核心配色，符合用户指定方向。石青、石绿的使用可由故宫特定建筑彩画研究作为邻近案例参考；金色在设计中用于强调历史宫廷气质，不代表有统一的藻井色彩比例。层叠结构转译为信息层级和空间纵深；颜料层积、微弱磨损与壁画式肌理是现代视觉语言，不是对单件历史对象的复原。图像示例不构成历史证据。

传统文献与博物馆教育材料中存在“藻井象征水、用于厌胜火灾”的解释。本 Skill 将其限定为传统观念解释，不描述成实际防火功能；若页面涉及该说法，须明确标注其为传统解释。
