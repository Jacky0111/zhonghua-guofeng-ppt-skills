# 天坛祈年

根据输入内容的篇幅、信息密度、逻辑关系和页面用途决定每页结构。以宝蓝琉璃的深邃光泽、朱红的垂直节奏、克制鎏金的焦点光线，以及汉白玉般的留白层次形成辨识度。先读 [`assets/README.md`](assets/README.md)；历史事实与现代诠释边界见 [`references/sources.md`](references/sources.md)。

## 设计语言

- **色彩：** 宝蓝为主要氛围色，朱红承担少量结构节奏，鎏金用于细线、局部高光和关键焦点，汉白玉用于稳定阅读空间与层叠留白。按内容和页面用途调整比例，避免金色铺满或红色形成僵硬边框。
- **材质与光影：** 以深蓝釉面般的细腻光泽和渐层表现苍穹纵深；朱红呈沉稳、微哑的色面；金色保持细而克制；汉白玉以柔和细纹和层叠边界提供呼吸空间。材质可进入图表、卡片与组件，但不能损害信息辨识度。
- **空间意境：** 通过渐层、局部弧线、向心光感、纵深及留白表达敬天祈年的静穆感。圆形关系可用不完整、偏移或若隐若现的弧线提示，不要求每页出现；方形信息组织与柔和曲线可并用。
- **建筑美学转译：** 将琉璃瓦的釉光转为色彩层次，将立柱的垂直韵律转为排版节奏，将攒尖顶的递进关系转为聚合层次，将台基转为稳定的留白或水平层叠。除非内容明确讨论建筑本身，不直接展示祈年殿、屋顶、立柱、台基或传统具象纹样。
- **内容自适应：** 时间脉络可用时间轴或分期叙事；礼制流程可用步骤、关系图或并列结构；概念阐释可用大标题、短注释和留白；数据内容按真实关系设计图表。以上仅为可选结构，不是模板。
- **灵活构图：** 每页可改变重心、方向、留白、组件尺度和信息组织。风格一致性来自蓝、红、金、白的关系、釉面光泽、垂直节奏和天地纵深，不来自反复使用同一圆环、弧线或标题位置。
- **可读性：** 正文、小字和图表标签放在对比稳定、纹理较弱的区域；避免文字落在金色高光或蓝色明暗交界处。必要时使用不透明阅读底、局部降纹理或增加明暗对比。
- **史实边界：** 祈年殿建筑形制和名称经历变化。不得把现存建筑描述为 1420 年原建的圆形祈年殿；相关年代、礼制与命名以 [`references/sources.md`](references/sources.md) 所列来源为准。视觉示例不是史料或建筑复原。
