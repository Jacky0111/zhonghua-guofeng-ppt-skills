# 天坛祈年：史实来源与视觉转译

## 已核实事实

- 1420 年建成的初始主体建筑为矩形大祀殿，承担天地合祀；不能将现存祈年殿形制追溯为 1420 年原貌。
- 1531 年起在该处确立孟春祈谷礼；1545 年建成圆形大享殿；1751 年改称祈年殿。
- 祈年殿用于明清皇帝于孟春祈求五谷丰登。圆形殿宇与天圆观念、蓝色琉璃瓦与苍天意象有关。
- 1889 年祈年殿遭雷击焚毁，后重建。

## 现代视觉诠释

宝蓝、朱红、鎏金和汉白玉共同构成当代演示设计的色彩与材质语言，并非对历史建筑颜料、材料或光线的测色复原。蓝色渐层和釉面光泽用于表达苍穹纵深；朱红色面转译垂直秩序；细金线与局部高光承担视觉聚焦；汉白玉色层用于留白和稳定。偏移弧线、向心层次及圆与方的关系属于现代抽象表达，不是历史建筑图纸。
