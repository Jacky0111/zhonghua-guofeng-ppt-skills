# 建盏曜变

按内容选择页面结构，以玄黑、幽蓝和随光变化的斑彩建立统一设计语言。先阅读 `assets/README.md`，按需查看相关示例；历史表述遵循 `references/sources.md`，区分馆藏证据与现代视觉转译。

## 视觉语言

- **色彩：** 以玄黑、炭黑和墨蓝作底；用深靛、钴蓝、幽蓝及少量蓝紫表达斑彩晕光。银白只用于小面积文字、细线或点状高光，是现代设计提亮，不是历史釉色结论。
- **材质与纹理：** 表现黑釉的深度、润泽和光线变化。用大小不一、边缘不规则的晶斑群及其周围渐变晕彩形成识别特征；纹理可细密聚集，也可留白疏朗。避免通用星空、规则圆环、霓虹科技纹或无依据的开片图样。
- **光泽：** 让蓝色虹彩局部显现、随页面焦点变化；保留黑釉大面积暗部和细微层次，避免均匀铺满的蓝色渐变或过曝银光。
- **构图与层级：** 依据内容关系选择标题页、说明图、时间线、对比或数据组件等结构。可将斑彩纹理延伸至背景、卡片和图表，但应在文字密集区降低纹理强度，或设置稳定的深色文字净区。
- **字体与可读性：** 标题可采用克制的宋体气质，正文使用清晰的现代字体。正文、小字和图表标注须与底色有足够对比；不得把文字置于高亮斑彩或频繁变化的光晕上。
- **器物呈现：** 默认以抽象黑釉、晶斑与晕彩表达风格，不要求生成建盏器物。只有内容确有需要时才加入器物图。
