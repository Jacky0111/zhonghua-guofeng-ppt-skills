# 建盏曜变：来源与边界

## 已核实资料

- 故宫博物院资料将建窑黑釉茶盏与宋代斗茶风尚联系起来，并列举兔毫、鹧鸪斑、曜变等不同观感。
- 故宫博物院对曜变器的说明提到黑釉地、斑点和蓝色光晕；有关观看角度与光线影响晕彩的描述，应以具体器物记录为准。

## 需谨慎的历史主张

曜变名称的历史使用、形成机理、存世器物范围与数量可能涉及研究讨论。本 Skill 不断言单一成因或固定存世数量，也不把一件器物的外观泛化为全部建窑黑釉器的共同属性。图像预览不是历史证据。

## 现代视觉转译

玄黑底场、幽蓝与蓝紫晕彩、局部渐变和晶斑细节依据馆藏资料描述提炼为屏幕视觉语言，不是釉色的精确复原。银白高光是现代演示文稿的阅读与层级设计手段，不代表历史釉色。屏幕发光、文字色彩与组件纹理也都属于现代转译。
