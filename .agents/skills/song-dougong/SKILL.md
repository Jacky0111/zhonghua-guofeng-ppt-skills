# 宋式斗拱演示文稿设计

当用户希望以宋式斗拱美学设计或改进演示文稿时使用。让页面结构响应输入内容的长度、信息密度、逻辑关系和叙事用途。开始设计前阅读 [assets/README.md](assets/README.md)；涉及历史背景或建筑主张时，按需查阅 [references/sources.md](references/sources.md)。

## 设计语言

- **色彩：** 以木褐建立温润的视觉重心，以青灰提供冷静层次，以米白留出清晰的阅读空间。色彩比例随内容调整；这些颜色是现代设计选择，不是对宋代建筑原貌的历史测色。避免全页木褐、纯色空背景或将纹理铺满文字区。
- **承托与联络：** 将斗拱构造中承托、过渡、联络的关系转译为页面的信息层级、组件衔接、重点支撑和视觉重心。让设计的各部分彼此建立关系，不把斗、拱、昂逐一画成装饰对象。
- **穿插与层递：** 通过错位、遮叠、前后层次、局部延伸和视线引导表达构件之间的组织关系。根据内容选择曲面、水平层次或局部结构节奏，不要求每页出现相同的几何形态，也不要制作构件拆解图来代替完整页面设计。
- **模数与比例：** 可把“材分八等”转译为字号、间距、对齐、组件尺度的成组关系；它只是设计启发。《营造法式》的材分制度主要规范大木作构件尺寸，不应表述为控制整座建筑所有尺度的统一比例，更不要把八等机械地变成每页八个模块。
- **材质与空间：** 以细腻、克制的木纹、青灰色哑光表面、柔和侧光、接触阴影和遮挡层次营造厚度。材质进入背景、阅读区或组件时都须服务信息；避免仿旧纸张、强烈高光、扁平纯色和堆叠真实构件。
- **宋式气韵：** 追求清雅、理性、含蓄、精巧、疏密有致。通过比例、空间、节奏和精度共同呈现，不依赖书法、古风边框或传统装饰符号。
- **内容自适应：** 年代关系可采用时间叙事；规范和尺度可用层级或编辑式比较；结构含义可用关系图或错位叙述；内容密集时优先组织清楚的阅读区。以上是可选方法，不是固定版式。按实际内容设计图表、表格、流程和信息组件。
- **可读性：** 正文、小字和图表标注放在明暗稳定、纹理较弱的位置。避开木纹高反差、强光及材质交界；需要时增加米白阅读底、减弱局部纹理或调整文字对比度。

## 史实边界

“宋式斗拱”并非对所有地区、建筑类型和时期的唯一形制概括。引用《营造法式》、构件制度或具体建筑实例时，遵循 [references/sources.md](references/sources.md) 的出处和范围说明；区分可核实史实与现代设计转译。

## 多语言生成

本节优先于本 Skill 中任何与语言、字体或阅读方向有关的表述。

- **指令语言不等于输出语言：** 本文件用中文撰写，不限定演示文稿的语言。
- **自动决定输出语言：** 用户指定时按指定执行；否则依据用户本次输入的语言与意图自动判断（页面内容、请求措辞、上下文），不固定为任何语言，也不以仓库或指令语言为默认。支持任意语言及多语言混合。
- **原文不可擅改：** 不得擅自翻译、改写、简繁转换或转写用户提供的内容（含专名、引文、代码、数字与单位）。仅在用户明确要求时翻译。页面上的原文须逐字符一致（含标点、大小写、数字与单位）：不补句末标点，不替换全角、半角或其他标点；换行只改位置，不增删字符。指定的输出语言与原文不同且未说明是否翻译时，无须固定追问：依据用户输入自动决定新增文字的语言，所给原文保持原样。
- **按文字调整版面：** 依实际文字长度调整字号层级、换行、分栏与页数，不靠缩到难以阅读或裁切来塞入内容。
- **字体兼容：** 选用当前环境可用且覆盖目标文字的字体，避免缺字与伪造字形。本 Skill 提到的宋体、黑体等气质，在其他文字中换用相近的衬线或无衬线字体。
- **阅读方向：** 阿拉伯文、希伯来文等从右到左文字须调整对齐、阅读顺序与时间轴、流程方向；混排时数字、拉丁词与标点保持正确。仅在文字适用且内容需要时使用竖排。
- **适用范围：** 本节约束演示内容与版面。版式或“简短说明”类建议不授权删减、压缩用户原文；原文与可核查史实或本 Skill 的史实边界冲突时，指出问题，经用户确认后才修改。
- **换语言不换风格：** 色彩、材质、纹理、光泽、层次、格调与意境保持本 Skill 的设计语言。示例图中的中文只是示例，不得照抄，也不代表默认语言。
- **交付检查：** 调用图像生成时在提示词中逐字给出页面文字，并写明不得增删或替换标点。交付前对照画面实际文字与用户原文逐字核对（含每行行末）；不一致则修正或如实告知，报告以画面实际内容为准。同时检查缺字、错字、断行与方向。图像生成对该文字渲染不可靠时，改用可编辑文本层；做不到时如实告知用户。
