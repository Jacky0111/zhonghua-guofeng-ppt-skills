# 宋式斗拱：史实来源与设计转译

## 可追溯来源

- [中国国家博物馆：《营造法式》](https://www.chnmuseum.cn/zp/zpml/gjwxbt/202203/t20220301_254037.shtml) — 介绍李诫编撰的《营造法式》于1100年完成，以及其文字制度与斗拱、梁柱等构件图样。
- [故宫博物院：《营造法式》](https://www.dpm.org.cn/ancient/mingqing/149329.html) — 记载李诫于1097年奉敕重修，1100年修订完毕、1103年付梓；并说明大木作以“材”为祖、材分八等。
- [故宫博物院院刊：《〈营造法式〉大木作控制性尺度规律研究》（2015年第6期）](https://img.dpm.org.cn/Uploads/File/2018/06/04/u5b15212a9a148.pdf) — 对材分制度的适用范围作出限定：主要用于大木作构件尺寸，不应简单等同于控制整座建筑开间、进深、柱高等总体尺度的通用模数。
- [清华大学艺术博物馆馆刊（2021年第3期）](https://www.artmuseum.tsinghua.edu.cn/xsyj/gk/202111/W020211102411379529715.pdf) — 讨论中国建筑的斗拱与比例体系，并引用梁思成对斗拱在梁枋与柱间发挥过渡、联络作用及兼具结构、装饰性的概括。该内容应作为研究论述引用，不取代具体建筑和时代的个案证据。

## 事实、推断与未知

- **已核实事实：** 《营造法式》在1100年修订完成、1103年刊行；书中记录营造制度、构件尺寸和图样。大木作材分八等，以材作为基本尺度之一。
- **已核实的范围限制：** 材分主要规范构件尺寸，不等同于控制每座建筑全部总体尺度的统一比例系统。
- **设计推断：** 把承托、过渡、联络、层递、尺度关系映射为版面层级、组件连接、视觉节奏和材质层次，是现代设计转译，不是历史文献对幻灯片构图的规定。
- **现代设计选择：** 木褐、青灰、米白为本 Skill 的视觉调色方向，不代表宋代斗拱或宋代建筑存在唯一、普遍适用的色彩方案；纹理、光影和空间效果也是当代表达。
- **未知与边界：** 宋代建筑因地区、功能、等级、年代及后世修缮而异；单一文献或单座建筑不能代表所有宋式斗拱。引用具体构造和实例时需补充针对性来源，不应根据生成示例推断历史尺寸或原貌。
