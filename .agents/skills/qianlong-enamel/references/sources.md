# 乾隆珐琅彩：来源与转译边界

## 历史资料

- [故宫博物院：珐琅彩梅花牡丹纹碗与工艺说明](https://www.dpm.org.cn/collection/ceramic/227499.html)：用于核查“瓷胎画珐琅”术语及相关工艺介绍。
- [故宫博物院：乾隆款珐琅彩花卉纹瓶](https://intl.dpm.org.cn/Ceramicsis/81104.html)：单件馆藏例，可用于了解彩料和装饰形式；不能推为所有乾隆珐琅彩器的通例。
- [故宫博物院：珐琅彩开光山水诗句瓶](https://www.dpm.org.cn/collection/ceramic/227071.html)：单件馆藏与相关工艺资料，不作为页面图案模板。
- [故宫博物院：胭脂紫轧道珐琅彩直颈瓶](https://www.dpm.org.cn/collection/ceramic/227721.html)：单件色地与装饰工艺资料，不据此复刻纹样。
- [大都会艺术博物馆：18 世纪中期釉上彩与金彩瓷盘](https://www.metmuseum.org/art/collection/search/50034)：辅助理解相关时代的釉上彩与金彩背景；其分类术语不与珐琅彩无差别互换。

## 已核实事实、设计推断与未知

- **已核实：** 故宫资料将珐琅彩瓷称为“瓷胎画珐琅”，并记载其在清代宫廷发展。具体器物的施彩、题诗、纹饰和金彩组合各有不同。
- **现代转译：** 本 Skill 采用用户指定的粉红、松石绿、金色，辅以瓷白留白和深墨文字；通过抽象色层、釉面微光、细节密度及现代排版表达华贵、精致、典雅。这是设计语言，不是历史器物的统一配色或外观复原。
- **谨慎事项：** 珐琅彩、粉彩、洋彩等术语会随历史语境和现代馆藏分类而异。涉及具体器物或工艺主张时，应核对对应馆藏记录；不能将单件器例泛化为整个类别。

## 使用原则

从资料中提炼色彩关系、光泽、精工感、层次与艺术气质。器物上的花卉、龙凤、山水、人物、诗印及边饰不应仅因其存在于参考器物上就进入幻灯片。只有当内容确实讨论具体图案，或其具象表达对理解不可替代时才使用，并明确出处及使用范围。
