# 明代故宫

根据内容长度、信息密度和逻辑关系决定每页构图，以朱红、帝王金与琉璃白，以及矿物肌理、斜光和空间层次维持风格一致。先阅读 [`assets/README.md`](assets/README.md)；历史依据与现代转译边界见 [`references/sources.md`](references/sources.md)。

## 视觉语言

- **色彩：** 朱红与帝王金承担视觉重点，琉璃白提供阅读空间，汉白玉色可用于局部浅色层次。按内容调整比例；这是一套现代设计配色，不是明代建筑颜料的测色复原。
- **材质与光影：** 以细密矿物墙面肌理、暖光掠过朱红表面的明暗变化、柔和长影和琉璃白的温润细纹形成空间感。纹理要融入页面系统，可出现在底色、文字区边缘、数据图形与组件中；不要求展示建筑或器物。
- **气质：** 庄严、恢宏、沉稳、精致。用色彩重量、光影纵深、留白和细节密度表达宫廷秩序，避免仿古装饰、满版金色和僵硬的对称方框。
- **排版：** 让内容决定构图。依信息关系选择时间线、因果关系、比较、数据图表、叙事留白或其他结构；标题、色面、光带和组件位置均可变化，不将示例页固化为模板。
- **建筑转译：** 可将宫墙的面与影、琉璃表面的光泽、台基层次、屋面起伏和结构节奏转为抽象的色块走势、光影边界、层叠关系与几何韵律。除非内容确实讨论具体建筑或构件，不直接拼贴宫殿、屋檐、斗拱、龙纹等具象元素。
- **可读性：** 正文、脚注、图表标注放在低纹理稳定区域，与底色保持清晰对比。避免文字跨越高光、金色光带或明暗频繁变化处；必要时降低局部纹理或增加纯色/半透明阅读区。

## 多语言生成

本节优先于本 Skill 中任何与语言、字体或阅读方向有关的表述。

- **指令语言不等于输出语言：** 本文件用中文撰写，不限定演示文稿的语言。
- **自动决定输出语言：** 用户指定时按指定执行；否则依据用户本次输入的语言与意图自动判断（页面内容、请求措辞、上下文），不固定为任何语言，也不以仓库或指令语言为默认。支持任意语言及多语言混合。
- **原文不可擅改：** 不得擅自翻译、改写、简繁转换或转写用户提供的内容（含专名、引文、代码、数字与单位）。仅在用户明确要求时翻译。指定的输出语言与原文不同且未说明是否翻译时，无须固定追问：依据用户输入自动决定新增文字的语言，所给原文保持原样。
- **按文字调整版面：** 依实际文字长度调整字号层级、换行、分栏与页数，不靠缩到难以阅读或裁切来塞入内容。
- **字体兼容：** 选用当前环境可用且覆盖目标文字的字体，避免缺字与伪造字形。本 Skill 提到的宋体、黑体等气质，在其他文字中换用相近的衬线或无衬线字体。
- **阅读方向：** 阿拉伯文、希伯来文等从右到左文字须调整对齐、阅读顺序与时间轴、流程方向；混排时数字、拉丁词与标点保持正确。仅在文字适用且内容需要时使用竖排。
- **适用范围：** 本节约束演示内容与版面。版式或“简短说明”类建议不授权删减、压缩用户原文；原文与可核查史实或本 Skill 的史实边界冲突时，指出问题，经用户确认后才修改。
- **换语言不换风格：** 色彩、材质、纹理、光泽、层次、格调与意境保持本 Skill 的设计语言。示例图中的中文只是示例，不得照抄，也不代表默认语言。
- **交付检查：** 检查缺字、错字、断行、标点与方向。图像生成对该文字渲染不可靠时，改用可编辑文本层；做不到时如实告知用户。
