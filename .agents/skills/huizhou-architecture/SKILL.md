# 徽派建筑

当用户希望以徽派建筑美学设计或改进演示文稿时使用。让内容长度、信息密度、逻辑关系和叙事用途决定每页构图；以黑、白、灰的明暗层次、真实体量、自然材质与空间纵深维持风格辨识度。开始设计前阅读 [`assets/README.md`](assets/README.md)；涉及历史、地域或工艺主张时按需查阅 [`references/sources.md`](references/sources.md)。

## 设计语言

- **色彩：** 以墨黑、粉墙白、黛瓦灰为核心，通过明度和材质反射建立层次，不依赖额外鲜艳色制造风格。按页面内容调整黑白灰比例，保留清楚的阅读区域。
- **体量与空间：** 将黛瓦层叠、屋面倾斜与外挑、马头墙高低错落、墙体转折和院落纵深转译为具有厚度的面、体块与空间关系。用前中后景、透视、遮挡、承托及错层营造真实空间；不展示完整建筑，不把屋顶轮廓当作贴纸或重复边框。
- **材质与光影：** 以细密而有变化的瓦面层叠、粉墙哑光肌理、灰色石材自然纹理、柔和环境光、接触阴影、边缘高光和明暗过渡表现实体感。避免纯色平涂、二维剪影、扁平折线、纸片式堆叠及为立体而立体的孤立装饰。
- **构图与秩序：** 以高低错落、斜向延展、局部围合、框景与留白组织页面。结构应自然进入标题区、阅读区、图表或信息组件，与内容层级共同构成空间；不要求每页出现相同的檐角、墙体或三维形状。
- **内容自适应：** 年代和沿革可采用叙事序列或对照；院落空间可用关系图或分层说明；工艺、材料和地域差异可用编辑式分组、比较图或简洁标注。以上仅为可选表达，组件与版式由实际信息决定。
- **气质：** 保持清雅、静谧、质朴、内敛与现代建筑编辑设计的精致感。让结构化的信息与抽象空间意境并存，避免刻意堆砌尖角、固定对称构图或空洞的黑白背景。
- **可读性：** 正文、脚注、图表标注放在明暗稳定、低纹理的区域；避免文字跨越瓦面细节、阴影交界和高光。必要时降低局部纹理、加阅读底色或扩大留白，不以材质展示牺牲对比度。
- **史实边界：** 徽州建筑地域、年代与构造存在差异。西递、宏村及徽州三雕等具体案例不得泛化为全部徽派建筑。历史事实、研究范围与现代视觉转译边界见 [`references/sources.md`](references/sources.md)。

## 多语言生成

本节优先于本 Skill 中任何与语言、字体或阅读方向有关的表述。

- **指令语言不等于输出语言：** 本文件用中文撰写，不限定演示文稿的语言。
- **自动决定输出语言：** 用户指定时按指定执行；否则依据用户本次输入的语言与意图自动判断（页面内容、请求措辞、上下文），不固定为任何语言，也不以仓库或指令语言为默认。支持任意语言及多语言混合。
- **原文不可擅改：** 不得擅自翻译、改写、简繁转换或转写用户提供的内容（含专名、引文、代码、数字与单位）。仅在用户明确要求时翻译。指定的输出语言与原文不同且未说明是否翻译时，无须固定追问：依据用户输入自动决定新增文字的语言，所给原文保持原样。
- **按文字调整版面：** 依实际文字长度调整字号层级、换行、分栏与页数，不靠缩到难以阅读或裁切来塞入内容。
- **字体兼容：** 选用当前环境可用且覆盖目标文字的字体，避免缺字与伪造字形。本 Skill 提到的宋体、黑体等气质，在其他文字中换用相近的衬线或无衬线字体。
- **阅读方向：** 阿拉伯文、希伯来文等从右到左文字须调整对齐、阅读顺序与时间轴、流程方向；混排时数字、拉丁词与标点保持正确。仅在文字适用且内容需要时使用竖排。

- **换语言不换风格：** 色彩、材质、纹理、光泽、层次、格调与意境保持本 Skill 的设计语言。示例图中的中文只是示例，不得照抄，也不代表默认语言。
- **交付检查：** 检查缺字、错字、断行、标点与方向。图像生成对该文字渲染不可靠时，改用可编辑文本层；做不到时如实告知用户。
