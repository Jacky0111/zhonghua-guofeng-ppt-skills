# 徽派建筑：资料来源与设计转译边界

## 调查来源

- [联合国教科文组织：西递、宏村古村落](https://whc.unesco.org/en/list/1002/)：介绍西递、宏村的历史范围、传统村落特征、建筑与水系等。相关年代和保存特征仅适用于该遗产地，不能代表全部徽派建筑。
- [西递、宏村申遗文件](https://whc.unesco.org/uploads/nominations/1002.pdf)：提供遗产地建筑格局、住宅院落及天井空间的申报材料。涉及具体空间功能时应以文件原文和对象范围为准。
- [寿焘、成玉宁：《环境构形——徽州天井院“空间景观模型”解析》，《世界建筑》2023年第1期](https://sjzj.cbpt.cnki.net/portal/journal/portal/client/paper/7655eb2746d606ebf79206bf59b5b2ec)：分析天井院的自然要素、形体结构、空间层序、景观界面与环境构造；结论不应脱离研究对象泛化。
- [中国非物质文化遗产网：徽州三雕](https://www.ihchina.cn/project_details/11243)：介绍徽州三雕中的砖雕、木雕、石雕及工艺文化背景。

## 事实、推断与未知

- **资料支持的事实：** 西递、宏村保存有特定历史时期形成的村落格局、传统建筑与水系；徽州三雕指砖雕、木雕和石雕工艺。它们是具体遗产地与工艺门类的资料，不代表所有徽州建筑在时代、形制、材料或装饰上完全一致。
- **设计推断：** 黑白灰比例、瓦面体量、粉墙哑光、石材纹理、前后景层叠、透视、柔和环境光及接触阴影是本 Skill 的现代视觉转译，用于传达徽派建筑的空间与材料感，不是历史色彩测定、建筑复原或传统工法的直接复现。
- **未知与边界：** 本组预览并未对单座建筑进行测绘，也不提供可据以复原的尺度、屋面构造、墙体材料配方或历史色彩数据。需要精确讨论建筑年代、构件或工艺时，应补充对应地域、建筑个案和可核查研究来源。

## 使用原则

让空间关系和材质进入整页信息系统，而不是作为独立屋顶插画。用户内容若讨论具体建筑、天井或三雕，可有目的地呈现相关对象并标明出处；否则优先抽象表达体量、层次、边界、光影和留白。示例图片不作为史料，也不得用来推断历史事实。
